# Intellectual Property

## Code

All CasperProver code is authored by the maintainers or contributed
under the repository's Contributor Licence Agreement (see `SECURITY.md`
and `LEGAL/`). Third-party dependencies are tracked in the CycloneDX
SBOMs under `sbom/`.

## Patents

CasperProver does not hold patents today. The patent posture is
documented at `docs/PQ_HONESTY.md` §patents (single source of truth).
The maintainers may file for defensive purposes; if that changes, the
change lands here and in that file with a linked artefact.

## Trademarks

"CasperProver" is used in commerce by the maintainers. Formal
trademark registration is deferred pending commercial-launch scope.

## Open-source posture

- Source-available public repo on GitHub.
- Third-party dependencies covered by their upstream licences.
- Contributions accepted under the repository's CLA.
